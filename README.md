# Quick Dot Game

A simple reaction-time game built with HTML, CSS, and JavaScript. Click the dot before it disappears, and test how fast you can react!

## Features
- Random dot positioning
- Increasing difficulty with each successful click
- Score tracking
- Game-over screen with final score
- Minimal dark-themed UI

## Technologies Used
- **HTML** — Page structure
- **CSS** — Styling and layout
- **JavaScript** — Game logic, timers, and scoring

## How to Play
1. Click **Start Game**.
2. Click the dot before the timer runs out.
3. Keep clicking as the game gets faster.
4. Try to achieve your highest score!

## Run Locally
Download or clone this repository and open `index.html` in your browser.
